# Data Visualization — Employee Management Data

## Deskripsi Proyek
Proyek ini merupakan tugas Studi Kasus Data Visualization 2026 untuk mata kuliah Data Mining. Proyek ini menggunakan Python di Google Colab untuk menganalisis dan memvisualisasikan data karyawan berdasarkan departemen, gaji, masa kerja, dan tahun perekrutan.

## Tujuan
- Memahami karakteristik dataset karyawan.
- Membandingkan distribusi gaji antar-departemen.
- Menganalisis hubungan masa kerja dengan gaji tahunan.
- Mengamati jumlah perekrutan karyawan.
- Menyajikan hasil analisis dalam bentuk visualisasi data.

## Tools dan Library
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## File dalam Repository
- `2418005DataVisualization.ipynb` — notebook berisi proses analisis, visualisasi, dan kesimpulan.
- `README.md` — dokumentasi proyek.

## Visualisasi yang Digunakan
1. Histogram distribusi gaji tahunan.
2. Bar chart jumlah karyawan berdasarkan departemen.
3. Boxplot gaji tahunan berdasarkan departemen.
4. Scatter plot hubungan masa kerja dengan gaji tahunan.
5. Line chart jumlah perekrutan berdasarkan bulan.
6. Heatmap korelasi antarvariabel numerik.

## Temuan Utama
- Setiap departemen memiliki 4 karyawan dalam dataset.
- Information Technology memiliki median gaji tahunan tertinggi, yaitu USD 65.000.
- Customer Service memiliki median gaji tahunan terendah, yaitu USD 47.500.
- Korelasi antara masa kerja dan gaji tahunan relatif lemah pada dataset ini.
- Dataset mencakup tanggal perekrutan sepanjang tahun 2023.

Temuan tersebut menggambarkan dataset yang dianalisis dan tidak selalu mewakili kondisi perusahaan secara umum.

## Privasi Data
Visualisasi menggunakan data yang telah disiapkan untuk analisis. Informasi identitas seperti nama lengkap dan ID karyawan tidak perlu disertakan dalam file publik.

## Cara Menjalankan
1. Buka file `2418005DataVisualization.ipynb`.
2. Buka notebook menggunakan Google Colab.
3. Siapkan dataset sesuai format yang diminta oleh notebook.
4. Jalankan setiap sel secara berurutan.
5. Amati grafik dan kesimpulan yang dihasilkan.
